Privacy Policy — EvilRoyStudio Pin Scheduler

Last updated: October 8, 2026

EvilRoyStudio Pin Scheduler (“the App”) is a private tool operated by EvilRoyStudio (“we”, “us”). It is used only to manage EvilRoyStudio’s own Pinterest account. It is not offered, sold, or made available to any other person or business.

What the App does

The App connects to EvilRoyStudio’s own Pinterest account through the official Pinterest API in order to:

  • create and schedule Pins on EvilRoyStudio’s own boards
  • read the list of EvilRoyStudio’s own boards
  • read performance statistics (such as impressions, saves and clicks) for EvilRoyStudio’s own Pins

What information the App accesses

The App accesses only data belonging to the EvilRoyStudio Pinterest account that authorized it:

  • basic account information (username)
  • board names and IDs
  • Pins created by the account and their analytics
  • the access tokens Pinterest issues when the account is connected

The App does not access, collect or store information about other Pinterest users, followers or visitors.

How information is stored

All data is stored locally on a single computer controlled by EvilRoyStudio. It is not uploaded to any external server or database, apart from the Pinterest API calls needed to create Pins and read analytics. Access tokens are stored locally and are used only to communicate with Pinterest.

How information is used

Data is used only to publish EvilRoyStudio’s own content and to understand which Pins perform best. Data is never sold, rented, shared with third parties, or used for advertising profiles.

Affiliate links

Some Pins published by the App link to products on Amazon. As an Amazon Associate, EvilRoyStudio earns from qualifying purchases. Affiliate Pins are labeled with an affiliate disclosure. When you click such a link, you leave Pinterest and Amazon’s own privacy policy applies. The App itself does not track individual visitors.

Data retention and deletion

Data is kept only as long as needed to run the App. The Pinterest connection can be revoked at any time in Pinterest settings under Security and logins → Apps. Once it is revoked, the App can no longer access the account, and locally stored data can be deleted on request.

Children

The App is not directed at children and does not collect information from anyone.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new “Last updated” date.
